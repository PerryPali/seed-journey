FIELD NOTE / 01

飞走的，是种子
还是果实？

我们习惯把飞走的小伞叫作“种子”。更准确地说，它是一个内含一粒种子的干燥果实。果实上方的细长结构叫作喙，末端连接着一簇冠毛。

许多这样的果实聚在一起，形成熟悉的白色绒球。风来时，成熟的果实可以离开母株，开始传播。

回到画面看一看白色部分是冠毛；细杆下方的棕色小颗粒才是装着种子的果实。

FIELD NOTE / 02

没有翅膀，
怎样借风旅行？

冠毛由许多细丝组成，是疏松的结构，并不是一张密不透风的伞面。它增大了果实与空气相互作用的范围，帮助减缓下落。

蒲公英不会主动飞行。它借助气流移动，落在哪里与风和周围环境有关，并没有预先选好的终点。

回到画面看一看跟随种子观察轻微的摇摆；动画中的风线用于表现气流方向，不是实际可见的空气。

FIELD NOTE / 03

抵达土地，
为什么还要等？

落地不等于马上萌发。种子需要水分、氧气和适宜的温度；缺少合适条件时，旅程可能暂时停在这里。

蒲公英常在土壤表面或靠近表面的地方萌发，光也有助于萌发。因此，故事中的“入土”是浅层接触的示意，不表示需要深埋。

回到画面看一看一场雨代表水分条件的变化。冠毛伏下、飘离是叙事处理，脱落不是萌发的必要前提。

FIELD NOTE / 04

先向下扎根，
再向上寻找光。

条件合适时，胚根先伸出，帮助幼苗固定并吸收水分。随后，嫩芽向上生长，叶片逐渐展开。

蒲公英之后会形成贴近地面的基生叶丛。画面中的幼苗、根系和生长速度都经过简化，不代表真实比例或实际用时。

回到画面看一看根与嫩芽从同一个生命起点延伸。旅行没有结束，只是换了一种方式。
